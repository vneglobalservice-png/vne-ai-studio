# VNE AI Studio — AI Generation UI update
The site now includes an AI Photo Generation prompt interface with style and aspect-ratio choices. The button only validates/prepares a prompt; it does NOT generate an image yet.

## Publish
1. Extract this ZIP.
2. In your existing GitHub repository choose Add file > Upload files.
3. Upload these files, replacing existing files; keep index.html in repository root.
4. Commit changes. GitHub Pages will redeploy.

## Important
GitHub Pages is static hosting. Real AI image generation requires an image-generation provider and secure backend/API proxy. Never put private API keys in browser JavaScript. Claude can help build the code, but Claude itself is not an image-generation endpoint. Free tiers have quotas and can change.
